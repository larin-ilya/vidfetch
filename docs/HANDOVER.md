# Handover — VidFetch

> Дата: 2026-09-16. Статус: готово к приёмке.

## 1. Что доставлено

Полноценное desktop-приложение «VidFetch» (загрузчик видео/аудио) с исходным кодом
и собранными артефактами.

| Артефакт | Путь |
|----------|------|
| Исходный код (репозиторий) | GitHub: `larin-ilya/vidfetch` |
| Windows portable exe | `release/VidFetch 1.0.0.exe` (~119 МБ, x64) |
| Windows установщик (NSIS) | `release/VidFetch Setup 1.0.0.exe` (~119 МБ) |
| Распакованная сборка | `release/win-unpacked/` |

## 2. Как пользоваться

1. Запустить `VidFetch 1.0.0.exe` (portable) или установить через Setup.
2. Вставить ссылку (кнопка «Вставить ссылку» читает буфер обмена) или вставить вручную.
3. Приложение определит видео или плейлист.
4. «Скачать» → выбрать формат/качество/папку → «Начать загрузку».
5. Наблюдать прогресс → «Открыть папку» / «Показать в папке».

## 3. Как собрать из исходников

```bash
npm install
python -m pip install -r engine/requirements.txt
python -m pip install pyinstaller
python -m PyInstaller --onefile --name engine engine/engine.py   # -> engine/dist/engine[.exe]
# положить ffmpeg в build/ffmpeg/ (Windows: ffmpeg.exe)
npm start                  # dev
npm run dist:win           # NSIS + portable
npm run dist:linux         # AppImage + deb (сборка на Linux)
```

## 4. Известные ограничения

1. **Android** не покрывается: Electron не работает на Android, а yt-dlp (Python) на
   устройстве требует отдельного порта (Chaquopy/python-for-android) — отдельный
   тулчейн, не входит в текущую поставку. Архитектура (движок отделён от UI) это
   допускает: движок можно поднять как локальный сервис и написать нативную оболочку.
2. **WebM** зависит от наличия VP9/Opus в источнике: если у выбранного качества их
   нет, yt-dlp вернёт ошибку мёрджа (обрабатывается как «Ошибка» в UI).
3. **Пауза/Продолжить** реализованы через остановку текущего процесса и докачку
   (`continuedl`); возобновление зависит от поддержки `Content-Range`/фрагментов
   источником. Для большинства HTTP/HLS-потоков работает.
4. **Скорость/ETA** для живых потоков может отсутствовать (неизвестный размер).
5. **YouTube ToS**: скачивание с YouTube может нарушать их условия; используйте только
   для контента с правом на загрузку. Приложение не обходит DRM.
6. **Сборка Linux** собирается на Linux-машине (движок замораживается PyInstaller под
   Linux; кросс-заморозка из Windows невозможна). Конфиг готов, см. §3.
