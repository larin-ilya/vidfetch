# План поставки VidFetch

> Статус: **заблокирован** (locked). Дата блокировки: 2026-09-16.
> Зафиксирован после сигнала «go» и подтверждённого скоупа.

## 1. Цель (custom goal)

Создать настольное приложение в духе 4K Video Downloader — скачивание видео и
аудио из онлайн-сервисов — для Windows и Linux, с красивым современным
интерфейсом (не Godot), с модулем загрузки, отделённым от UI и заменяемым backend.

## 2. Стартовый триггер и допущения

- **Триггер:** сообщение пользователя «go» — подтверждение старта ранее
  обсуждаемого задания (не язык программирования Go).
- **Допущения:**
  - Интерфейс — Electron (Node 22 уже установлен), движок — Python + yt-dlp
    (уже установлен), ffmpeg — скачивается и бандлится отдельно.
  - Android-сборка на текущем тулчейне не покрывается Electron; фиксируется как
    ограничение и не фейкуется.
  - GitHub-пушинг выполняется по токену из `D:\AI_PROJEKTZ\ghp_for_push.txt`
    без раскрытия ключа (не в выводе, не в репозитории).

## 3. Вехи (milestones)

| # | Веха | Критерий готовности |

## 4. Определение завершения (completion definition)

Доставка считается завершённой, когда:
1. Репозиторий с полным исходным кодом запушен на GitHub.
2. Движок подтверждён реальной загрузкой (или анализом + минимальной загрузкой)
   с зафиксированным результатом.
3. UI запускается и рендерится (скриншот-доказательство).
4. Собраны и зафиксированы установочные артефакты Windows/Linux.
5. Handover-пакет (инструкции + ограничения + чек-лист приёмки) готов.

## 5. Вне скоупа / требует подтверждения

- Действия с учётными данными, платежами, деструктивными изменениями.
- Нативная Android-сборка (см. HANDOVER.md).
- Любое использование чужих товарных знаков/графики (интерфейс оригинальный).
