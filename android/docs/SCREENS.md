# Карта экранов и навигации

## Нижняя навигация (4 вкладки)

| Вкладка | Route | Экран | Иконка |
|---------|-------|-------|--------|
| Главная | `home` | `HomeScreen` | Home |
| Загрузки | `downloads` | `DownloadsScreen` | Download |
| История | `history` | `HistoryScreen` | History |
| Настройки | `settings` | `SettingsScreen` | Settings |

Переходы — через `NavHost` (Navigation Compose) + `NavigationBar`. Активная вкладка
подсвечивается. Состояние вкладок сохраняется (`saveState`/`restoreState`).

```
        ┌──────────── Главная ────────────┐
        │  URL ─▶ «Вставить»/«Скачать»     │
        │  анализ: idle→loading→result/error│
        └──────────────────────────────────┘
   ┌──────────┬────────────┬──────────┬───────────┐
 Загрузки   История    Настройки   (bottom nav)
```

## Состояния (для каждого списка)

| Состояние | Что показывается |
|-----------|------------------|
| `LOADING` | `CircularProgressIndicator` + подпись «Загрузка…» |
| `CONTENT` | список карточек загрузок |
| `EMPTY` | иконка + «Нет активных загрузок» / «История пуста» + подсказка |
| `ERROR` | иконка ошибки + текст + кнопка «Повторить» |

### Главная — поток состояний

| Состояние | Триггер | UI |
|-----------|---------|-----|
| `Idle` | старт | бейдж «Готово» |
| `Loading` | «Скачать» | спиннер + «Анализ ссылки…» |
| `Result` | валидный URL | карточка видео: название, автор, длительность, чипы качества, «Начать загрузку» |
| `Error` | пустой/неверный URL | красная карточка с сообщением |

### Переключение состояний для проверки

«Настройки → Демо-состояния списков» (Данные / Загрузка / Пусто / Ошибка) либо
меню-«ползунок» в шапке экранов «Загрузки»/«История».

## Тема

Светлая, тёмная и системная; переключение — «Настройки → Внешний вид». Тёмная тема
наследует ту же палитру (индиго-акцент, тёмная поверхность `#14151A`).
