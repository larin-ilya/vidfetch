# VidFetch

Современное desktop-приложение для скачивания видео и аудио из онлайн-сервисов.
Визуально и функционально вдохновлено 4K Video Downloader, но с собственным
оригинальным интерфейсом: минимализм, одна акцентная цветовая тема, скруглённые
карточки и короткий пользовательский сценарий.

> ⚠️ Используйте только для загрузки контента, на который у вас есть право
> (собственный контент, публичное достояние, материалы с разрешения автора).
> Приложение не обходит DRM и не предназначено для пиратства.

## Возможности

- Вставка ссылки в одно поле + автоматический анализ URL.
- Определение «видео» или «плейлист»; выбор отдельных элементов или всего плейлиста.
- Список активных и завершённых загрузок: превью, название, длительность, размер,
  прогресс (%), скорость, ETA.
- Пауза / Продолжить / Отмена / Открыть папку / Удалить.
- Диалог параметров: формат (MP4/MKV/WebM), качество (360p–2160p), только аудио
  (MP3/M4A/WAV + битрейт), субтитры и язык, метаданные и обложка, папка назначения.
- Настройки: папка по умолчанию, число одновременных загрузок, ограничение скорости,
  авто-вставка из буфера обмена, поведение после завершения, тема (светлая/тёмная/
  системная), язык (RU/EN).
- Обработка ошибок: неверная ссылка, недоступное видео, отсутствие качества,
  сетевой сбой, нехватка места, отмена.

## Архитектура

Модуль загрузки полностью отделён от интерфейса и работает как заменяемый backend:

```
┌──────────────────────┐      JSON-lines (stdin/stdout)      ┌──────────────────────┐
│  Electron UI         │ ──────────────────────────────────▶ │  engine.py           │
│  (renderer + main)   │ ◀────────────────────────────────── │  (yt-dlp + ffmpeg)   │
└──────────────────────┘        события: progress/done/error  └──────────────────────┘
```

- `engine/` — чистый Python-модуль (yt-dlp). Говорит по протоколу JSON-lines:
  методы `ping`, `analyze`, `download`, `pause`, `resume`, `cancel`.
- `electron/` — main + preload, спавнит движок и проксирует IPC.
- `renderer/` — интерфейс (HTML/CSS/JS), не знает о yt-dlp.

Движок можно заменить на нативный/удалённый, не трогая UI — контракт описан в
`engine/engine.py`.

## Требования для разработки

- Node.js ≥ 20, npm
- Python ≥ 3.10 с `yt-dlp` (`pip install -r engine/requirements.txt`)
- ffmpeg (бинарник в `build/ffmpeg/`; приложение само находит его)

## Запуск (dev)

```bash
npm install
python -m pip install -r engine/requirements.txt
npm start
```

## Сборка

```bash
# 1) заморозить движок в один бинарник (PyInstaller)
python -m pip install pyinstaller
python -m PyInstaller --onefile --name engine engine/engine.py
#   -> engine/dist/engine.exe (Windows) или engine/dist/engine (Linux)

# 2) положить ffmpeg в build/ffmpeg/
# 3) собрать установщики
npm run dist:win      # NSIS + portable
npm run dist:linux    # AppImage + deb
```
